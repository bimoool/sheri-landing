# Шери — лендинг UGC-экосистемы

Публичный адрес: https://sheri.bimoool.com

Сайт публикуется через GitHub Pages при каждом обновлении ветки `main`.

## Просмотр

В текущей сессии: http://127.0.0.1:3000

Для повторного запуска откройте терминал в этой папке:

```sh
pnpm install
pnpm dev --hostname 127.0.0.1 --port 3000
```

Откройте http://127.0.0.1:3000. Требуются Node.js 20.9+ и pnpm.

Проверка и запуск готовой сборки:

```sh
pnpm build
pnpm start --hostname 127.0.0.1 --port 3000
```

## Что реализовано

- Адаптивный одностраничный сайт на Next.js / React из исходного архива Optimus.
- Сохранены редакционная типографика, сетка, сдержанная палитра и код анимированной ASCII-сферы. Добавлены лаймовый акцент и фотографии из презентации.
- Экосистема, полный цикл работ, креаторы, мотивация, эксперты, интерактивная программа четырёх недель, референсы, три формата партнёрства, FAQ и контакты.
- Мобильное меню, навигация по разделам, управление вкладками с клавиатуры, раскрывающиеся ответы, поддержка reduced motion.
- Кнопки ведут в Telegram, email и телефон. Серверной формы и отправки в CRM нет; сайт не имитирует приём заявки.

## Где редактировать

- `app/page.tsx` — контент, контакт Telegram, карточки и интерактив.
- `app/globals.css` — оформление и адаптив.
- `app/layout.tsx` — заголовок, описание и язык.
- `public/media/*.webp` — оптимизированные изображения из презентации.
- `components/landing/animated-sphere.tsx` — переиспользованная сфера Optimus с поддержкой reduced motion.

Оригинальные компоненты Optimus сохранены как технический референс, но не подключены к странице. Исходные вложения не изменены. Вспомогательный electron-to-chromium закреплён на 1.5.426: версия из архива не проходила проверку возраста релиза. Проверка ошибок TypeScript включена.
